## Free Music Theory Lessons and Exercises

`musictheory.net` is one of the longest-standing and most widely trusted free resources for learning music theory. It offers clean, highly visual interactive tutorials and customizable exercises that help students build automaticity in note reading, ear training, chord identification, and key signatures.

### Key Resources

- **Interactive Visual Tutorials:** Step-by-step visual lessons covering staff basics, clefs, meter, scale degrees, triads, Roman numeral analysis, and seventh chords.
- **Customizable Drill Exercises:** Create custom parameters for note identification, key signature drill, interval ear training, chord construction, and keyboard identification.
- **Exercise Customizer for Teachers:** Generate custom web links that lock in specific parameters for assignments, allowing teachers to easily assess students' skills.
- **Essential Music Tools:** Access useful utilities, including a virtual piano keyboard, chord calculator, fretboard identifier, and metronome.
