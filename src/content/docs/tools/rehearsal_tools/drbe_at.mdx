## The Iconic Rehearsal Metronome, Reimagined for the Web

DrBe.at is an ad-free, web-based virtual metronome that emulates the interface, sound profiles, and functionality of the classic Roland/Boss Dr. Beat (DB-90). Built by composer and developer Owen Meldon, it provides musicians and ensemble directors with the legendary subdivision-mixing workflow without requiring dedicated hardware.

### Key Features

<CardGrid>
	<Card title="Authentic Subdivision Faders">
		Adjust independent volume sliders in real time for quarter notes, eighth notes, sixteenth notes, and triplets to customize subdivisions for any exercise or piece.
	</Card>
	<Card title="Human Voice & Mechanical Clicks">
		Switch between classic high-cut metronome clicks, electronic chimes, and the iconic human voice count-in ("1, 2, 3, 4") beloved by percussionists and marching ensembles.
	</Card>
	<Card title="Podium Keyboard Shortcuts">
		Operate the metronome effortlessly from a rehearsal podium or practice stand using quick keybindings for play/pause, tempo nudging, and tap tempo.
	</Card>
	<Card title="Programmable Memory Presets">
		Store, recall, and toggle between custom tempos, time signatures, and subdivision configurations for specific rehearsal repertoire.
	</Card>
	<Card title="Tap Tempo & Wide Range">
		Quickly calculate beats per minute on the fly with responsive tap-tempo detection and accurate timing across extreme tempo spectrums.
	</Card>
	<Card title="Free & Open Community Tool">
		Lightweight, fully responsive for desktop and mobile, and completely free of paywalls, ads, or account registrations.
	</Card>
</CardGrid>
