## Short AMEB Piano Practice Tasks Between Lessons

Music Maestro supports early-grade piano students with focused browser practice for note reading, note values, rhythm, key signatures, intervals, terms, aural recognition, and general-knowledge preparation. Grade 1 practice is free without an account, while Grade 2-3 interactive access is available as a one-time unlock.

### Key Features

	<Card title="AMEB Piano Grade 1-3 Focus">

		Students can start Grade 1 activities in the browser without creating an account or entering payment details.
	</Card>
