*From the Flat.io website:*

## Collaborate on Sheet Music Online

Flat is an online collaborative music notation editor that allows composers and students to write sheet music together in real-time. Accessible from any web browser, Flat removes the friction of downloading software and sharing files.

### Key Features

<CardGrid>
	<Card title="Real-Time Collaborative Editing">
		Work on the same musical score with students, teachers, or co-writers simultaneously, with changes updating instantly on screen.
	</Card>
	<Card title="Classroom & LMS Integration">
		Flat for Education integrates seamlessly with Google Classroom, Canvas, Schoology, and Microsoft Teams for quick assignment delivery.
	</Card>
	<Card title="No Software Installation Required">
		Works completely in modern web browsers on Chromebooks, iPads, tablets, and computers.
	</Card>
	<Card title="Interactive Music Theory Exercises">
		Create custom worksheets, quizzes, and self-grading notation assignments to test students' music theory skills.
	</Card>
	<Card title="Flexible Import & Export">
		Easily import and export MusicXML, MIDI, and PDF files, making it easy to migrate existing sheet music catalogs.
	</Card>
	<Card title="Clean, Kid-Friendly Interface">
		Designed to be accessible to absolute beginners while still providing advanced notation controls for experienced composers.
	</Card>
</CardGrid>
