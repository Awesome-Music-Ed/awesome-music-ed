*From the Steinberg website:*

## The Next Generation of Music Notation Software

Dorico helps you write music notation, automatically producing printed results of exceptional quality — and plays it back with breathtaking realism. It is easy enough for anyone to learn, yet has hundreds of advanced capabilities, templates, and rules to satisfy even the most demanding professionals.

### Key Features

<CardGrid>
	<Card title="Intuitive Task-Based Interface">
		Work within clean, dedicated modes (Write, Engrave, Play, Print, Setup) designed to match your workflow stage exactly.
	</Card>
	<Card title="Unmatched Engraving Aesthetics">
		Based on decades of development, Dorico calculates horizontal spacing, vertical casting off, and collision avoidance with unparalleled artistry.
	</Card>
	<Card title="Direct MIDI Editing & Piano Roll">
		Edit MIDI data directly within the notation software using a DAW-like piano roll, automation lanes, and VST instrument integration.
	</Card>
	<Card title="Advanced Polyphonic Voice Handling">
		Input and manage complex multi-voice music on a single staff with absolute clarity and control.
	</Card>
	<Card title="Flexible Page Layout Controls">
		Construct custom master pages, music frames, and text boxes to create highly complex worksheets, hymnals, and full scores.
	</Card>
	<Card title="Lightning-Fast Input">
		Use rapid keyboard commands to input notes, articulations, and dynamics without touched a mouse.
	</Card>
</CardGrid>
