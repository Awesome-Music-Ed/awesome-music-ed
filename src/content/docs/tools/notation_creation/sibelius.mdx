## Create Beautiful Scores with the World's Best-Selling Notation Software

Sibelius is the professional standard for music notation and score engraving, used by composers, arrangers, publishers, and educators worldwide. With its sophisticated layout controls and robust classroom features, Sibelius enables developers of all skill levels to write, share, and publish professional-quality sheet music.

### Key Features

<CardGrid>
	<Card title="Magnetic Layout">
		Automate element placement to avoid collisions, instantly spacing notes, stems, and expressions beautifully.
	</Card>
	<Card title="Classroom Control & Templates">
		Educators can easily assign worksheets, lock down features for exams, and manage licenses across computer labs.
	</Card>
	<Card title="Flexible Input Methods">
		Input notes using a MIDI keyboard, standard computer keyboard and mouse, or scan existing scores using PhotoScore.
	</Card>
	<Card title="Professional Engraving Options">
		Customize staff styles, fonts, spacing algorithms, and page layouts to meet strict publication standards.
	</Card>
	<Card title="Seamless Cloud Sharing">
		Share interactive score previews online, allowing colleagues, students, or clients to play back and review work in any browser.
	</Card>
	<Card title="High-Quality Sound Library">
		Hear compositions performed with stunning realism using the Sibelius Sounds sample collection.
	</Card>
</CardGrid>
