Trello is a highly visual, Kanban-style project management application that helps individuals and teams organize tasks, track project status, and collaborate in real-time. It is widely used by educators for managing lesson planning schedules, performance tasks, and committee workflows.

## Key Features

- **Visual Kanban Boards**: Organise projects into columns representing phases (e.g., "To Do," "In Progress," "Done") to visualize workflows instantly.
- **Detailed Cards**: Create individual cards for tasks where users can add comments, set due dates, compile checklists, and attach documents.
- **Collaborative Workspaces**: Invite students, teachers, or booster members to boards to assign tasks and comment collectively.
- **Due Dates & Alerts**: Set specific timelines for tasks with automated email and browser notifications for upcoming deadlines.
