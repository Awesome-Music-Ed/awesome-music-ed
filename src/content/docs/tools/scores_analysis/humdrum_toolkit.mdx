## Command-Line Music Analysis

The Humdrum Toolkit is a set of command-line tools for analyzing and manipulating music represented in the Humdrum syntax (such as `**kern`). Developed for Unix and Linux systems, it offers modular, highly efficient tools for processing musical pitch, rhythm, harmony, and texture.

### Key Features

<CardGrid>
	<Card title="Flexible **kern Syntax">
		Utilizes a highly robust, human-readable symbolic representation of music that captures pitch, duration, bar lines, and ornaments in a simple text grid.
	</Card>
	<Card title="Modular Unix Philosophy">
		Features dozens of small, highly optimized command-line utilities (e.g. `mint`, `deg`, `key`, `solfa`) that can be piped together in terminal scripts.
	</Card>
	<Card title="Melodic & Harmonic Extraction">
		Extract intervals, scale degrees, and chord sequences instantly from thousands of files with simple regex-like search commands.
	</Card>
	<Card title="Academic Musicology Standard">
		A long-standing academic tool widely taught in computer musicology, performance analysis, and cognitive music studies.
	</Card>
</CardGrid>
