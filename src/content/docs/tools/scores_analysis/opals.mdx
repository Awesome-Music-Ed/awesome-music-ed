## Open-Source Library Automation

OPALS (Open-source Automated Library System) is a powerful, web-based, cooperative library automation system. It is a highly economical and customisable alternative to expensive proprietary library management software, making it a favorite for music departments, community choirs, and schools cataloguing their physical scores.

### Key Features

<CardGrid>
	<Card title="Economical Open-Source Hosting">
		Avoid heavy licensing fees with an open-source framework supported by cooperative hosting and custom development.
	</Card>
	<Card title="Easy Web-Based Cataloguing">
		Catalogue scores, orchestra folders, and textbooks from any internet-connected computer with a simple web interface.
	</Card>
	<Card title="Robust Search & OPAC">
		Provides an intuitive Online Public Access Catalog (OPAC) so students and directors can search for titles, composers, and instrument parts.
	</Card>
	<Card title="Inventory & Lending Management">
		Easily manage loans, returns, reservations, and inventory audits using standard barcode scanners and automatic email notices.
	</Card>
</CardGrid>
