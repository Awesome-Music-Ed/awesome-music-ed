# About

Awesome Music Ed is a community-driven, open-source project dedicated to curating and organizing the best tools, resources, and information for music educators. From band and orchestra directors to general music teachers, this website aims to provide a comprehensive, easy-to-navigate hub for all things music education.

# Contribute

We welcome contributions from the music education community! Whether you have a new tool to share, an update to an existing resource, or a suggestion for improvement, your input helps make Awesome Music Ed better for everyone.

Check out our [Contribution Guidelines](/contributions/) to learn how to get started, or start your submission by [creating a GitHub Issue](https://github.com/Awesome-Music-Ed/awesome-music-ed/issues).

# Donate

Awesome Music Ed is an open-source project. If you find these resources helpful, consider supporting the continued hosting and curation of this list. Your contributions go directly towards keeping this project alive and accessible for the music education community.
